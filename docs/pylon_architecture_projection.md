# Pylon-guided architecture projection

The congruent-shape atlas identifies structures recurring across the 73 commodity records. The architecture projection asks a stricter question: where does each pylon already exist in `ahead-rev-sim`, which invariants are qualified, which remain open, and what next transaction should shape the implementation?

The machine-readable authority is:

```text
src/ahead_rev_sim/data/congruent_shape_surface_projection.json
schemas/congruent-shape-surface-projection.schema.json
```

The current distribution is:

```text
contract_implemented   9
partial_contract       8
mapped_open            2
```

`contract_implemented` means that the software contract, refusal behavior, and deterministic tests exist. It does not imply measured physical closure. `partial_contract` means that the pylon has real surfaces but still lacks one or more required implementation or evidence stages. `mapped_open` means that the ecosystem shape is established and has a bounded design transaction, but no executable subsystem yet closes it.

## Implemented contracts

The bounded transition spine is present in accepted-output, execution, restoration, and consist proofs. Provider authority is constrained through the commodity registry and hitch contracts. Negative-space refusal is represented in MMIO, provider, physical-substrate, and EVP blockers. Self-describing cartridges use `physical-compute-mmio/v1`, typed descriptors, explicit capabilities, reset, fallback, and receipts. Reference twins execute through the same physical runtime. The lifecycle state machine distinguishes done, refused, and fault outcomes. The held-out physical assay separates computation from sensing. EVP is a non-scalar Pareto vector. Registry-gap dispatch converts every public record into a bounded transaction and lane.

These pylons are software-qualified. Their open work is external or physical: acknowledged provider substitution, measured cartridges, artifact-only audit, and measured complete-system comparison.

## Partial contracts

Provenance is SHA-256 sealed but does not yet carry a complete signed source-to-measurement transformation chain. Causal custody represents entropy, environment, calibration, and time but has not yet joined physical instruments in one synchronized execution. Semantic lowering covers instantiated instructions plus SVK and PCK, while composite lowering and executed Chipyard RTL remain open. Model fidelity distinguishes reference, simulated, and measured tiers, but no measured staircase has replaced the reference cartridges. The complete-system envelope and EVP schema exist, while a closed physical boundary does not. Composition is specified through MMIO, provider hitches, and a Chipyard candidate, while RTL and physical transport remain open. The materialization funnel reaches source-bound generator artifacts but not elaborated RTL or fabricated test structures. Intermittent recovery has strategy and energy contracts but no shared failure-trace execution.

## Mapped-open pylons

The scale-seam communication tax is recognized across chiplets, photonics, neuromorphic systems, and rack programmes. It now needs an executable tile-to-die-to-package-to-rack traffic and EVP model. The remote venue envelope is recognized across EBRAINS, THOR, ARIA, national prototyping facilities, and fabrication services. It now needs a portable submission bundle, raw-return receipt, local replay, and migration proof.

## Design rule

A new feature should not be justified only by the local mechanism it enables. It should identify the pylon it strengthens, the authority boundary it preserves, the current surface it extends, the open invariant it closes, and the receipt that proves the change. A new commodity record should project onto the pylon atlas before it can enter an execution lane. A retired provider or programme should leave the same pylon coverage behind through substitutes.

The control question is: which pylon moves from mapped-open to partial, or partial to implemented, and what receipt proves that movement without weakening an upstream authority layer?
